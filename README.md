# Авионика (PFD + Карта + ЗРК)

Кроссплатформенное GUI-приложение (Linux/macOS) для визуализации полётных данных, получаемых от `mandala` по HTTP в формате XML.

## Возможности

- **PFD-авионика** в стиле классических EFIS: искусственный горизонт, ленты скорости/высоты,
  компасная шкала, VSI, RPM, AGL, MSL, PS, GS, стрелка ветра. Сглаженные 60 Гц анимации,
  обновление данных с частотой 10 Гц.
- **Кроссплатформенно**: PySide6 + QtWebEngine, работает на Linux и macOS.
- **Индикаторы СВЯЗЬ и В ЗОНЕ ПУСКА** (масштабируются, могут быть «оторваны» в плавающее окно — встроено в Qt Dock).
- **СВЯЗЬ**: горит зелёным, если данные приходят и **меняются**; если 3+ сек значения
  «заморожены» или нет ответа — красный (защита от ложных срабатываний).
- **Карта** с поддержкой 3 слоёв: спутник (Esri), топография (OpenTopoMap), OSM.
  Смена слоя в меню «Карта».
  - Локальный прокси тайлов + дисковый кэш, проверка наличия тайла перед загрузкой.
  - Сохранение видимой области в указанном диапазоне zoom-ов.
  - Самолёт-иконка, поворачиваемая по `course`.
  - Трек полёта (включается/выключается).
  - Полигоны (создание/добавление точек через ПКМ или панель, сохраняются локально).
  - Точки стояния ЗРК (Тунгуска / Стрела-10 / Игла / Оса / Бук) с настраиваемым сектором стрельбы.
- **Настройки за паролем** (по умолчанию пароль: `admin`) — задаётся URL `mandala`.
- Все настройки/полигоны/ЗРК хранятся локально (JSON) в стандартной AppData-директории.
- Полная локализация интерфейса на русский язык.

## Установка

```bash
cd flight_app
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
python main.py
```

Зависимости: Python 3.10+, PySide6 (включает QtWebEngine), `requests`.

## Параметры mandala

Используемые теги XML:
`roll, pitch, yaw, altitude, airspeed, vspeed, course, rpm, agl,
windSpd, windHdg, gSpeed, gps_lat, gps_lon`.

## Раскладка

- Сверху-слева — авионика (док), справа от неё — два индикатора.
- Справа сбоку — панель «Объекты» (полигоны и ЗРК).
- Внизу/центр — карта.

Любую панель можно «оторвать» (drag за заголовок) и сделать отдельным окном/изменить размер.

## Контекстное меню карты (ПКМ)

- Добавить точку в текущий полигон
- Новый полигон от точки
- Точка стояния ЗРК (Тунгуска / Стрела-10 / Игла / Оса / Бук)
- Скопировать координаты

После добавления ЗРК — настройте азимуты сектора и дальность в правой панели.

## Зона пуска

Индикатор **В ЗОНЕ ПУСКА** горит зелёным, когда координаты самолёта попадают
в сектор хотя бы одной точки стояния ЗРК (азимут от севера по часовой, до `range_km` км).
